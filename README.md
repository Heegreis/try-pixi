# try-pixi

## Prerequisites

Install `pixi` and set autocompletion according [Getting Started - Pixi by prefix.dev](https://pixi.sh/latest/).
Currently, I use Pixi version: 0.42.1.

## Use Case: Pytorch

- [x] 1. Install pytorch (check GPU)
- [ ] 2. Install other dependencies

### Setup From Scratch

Following is the showcase of setting up from empty project. And will choose the way of `pyproject.toml`.

In the root directory of the project, run `pixi init --format pyproject`.

According to [Pytorch Installation - Pixi by prefix.dev #Installing from PyPi](https://pixi.sh/latest/features/pytorch/#installing-from-pypi) modyfied `pyproject.toml`.
